1. Resumen Ejecutivo y Problema de Negocio

Este proyecto analiza un conjunto de datos transaccionales de una tienda especializada en bicicletas, que comercializa diferentes marcas de bicicletas, accesorios y otros productos relacionados con el ciclismo.

El objetivo principal es evaluar el rendimiento de las ventas y la rentabilidad del catálogo de productos, identificando variaciones en los ingresos, productos y categorías con mayor participación, así como posibles ineficiencias en los márgenes de ganancia según categoría y región geográfica.

2. Limpieza y Transformación de Datos — Excel / Power Query

Antes del análisis y la visualización, se realizó un proceso de preparación y transformación de los datos para garantizar su calidad e integridad.

Estructuración de datos: conversión de los datos originales a una tabla estructurada en Excel para facilitar su procesamiento y posterior conexión con Power BI.
Corrección de tipos de datos: estandarización de fechas y campos numéricos como ingresos, ganancias, costos y cantidades.
Tratamiento de nulos y duplicados: revisión de registros incompletos y eliminación de duplicados o inconsistencias que pudieran afectar los resultados.
Estandarización: preparación de categorías, productos, marcas y regiones para facilitar su análisis.
3. Herramientas y Arquitectura
Preparación de datos: Excel / Power Query para limpieza y transformación.
Análisis exploratorio: SQL Server para consultas, agregaciones y validación de resultados.
Modelado y métricas: Power BI y DAX para crear medidas y relaciones entre los datos.
Visualización: Power BI para desarrollar un dashboard interactivo con indicadores, filtros y segmentaciones.
4. Hallazgos y Conclusiones

El análisis permitió identificar diferencias importantes en el rendimiento de las distintas categorías y productos de la tienda, tanto en volumen de ventas como en rentabilidad.

Entre los principales hallazgos se encontraron:

Algunas categorías concentran una mayor proporción de los ingresos totales, mientras que otras tienen una participación menor.
El nivel de ventas no necesariamente representa una mayor rentabilidad, debido a las diferencias existentes entre costos y márgenes.
Se identificaron productos con un volumen considerable de ventas pero con una contribución relativamente menor al margen de ganancia.
Las ventas presentan diferencias según la región geográfica, permitiendo identificar mercados con mayor actividad comercial.
El análisis de precios, costos y ganancias permite detectar productos que podrían requerir una revisión de estrategia de precios, costos o promoción.
