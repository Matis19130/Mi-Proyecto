#  Análisis de Ventas y Rentabilidad — Tienda de Bicicletas

## 1.  Resumen del Proyecto

Análisis de datos de una **tienda de bicicletas** que comercializa distintas marcas de bicicletas, accesorios y otros productos relacionados con el ciclismo.

El objetivo es analizar las ventas, costos y rentabilidad por producto, categoría y región.

## 2.  Limpieza y Transformación

- Estructuración y preparación de los datos.
- Corrección de tipos de datos.
- Tratamiento de valores nulos y duplicados.
- Estandarización de categorías, productos y regiones.

## 3.  Herramientas

- **Excel / Power Query:** limpieza y transformación.
- **SQL Server:** consultas y análisis exploratorio.
- **Power BI / DAX:** modelado, métricas y dashboard.

## 4.  Principales Hallazgos

- Algunas categorías concentran una mayor parte de los ingresos.
- Los productos con mayores ventas no necesariamente presentan los mayores márgenes.
- Se encontraron diferencias de rentabilidad entre categorías y regiones.
- El análisis permite identificar productos y categorías con oportunidades de mejora en rentabilidad.

## 5.  Conclusión

El proyecto permitió transformar datos de ventas en información útil para analizar **ingresos, costos y rentabilidad**, facilitando la identificación de productos y categorías con mayor impacto en el negocio.
